# instrumentation

This folder holds the source code of `lib/fastlane/plugin/qawolf/assets/instrumentation.dylib`.

- CI copies this folder from the QA Wolf main repository on each change. The commit message names the source commit.
- The dylib and this folder in one commit come from the same source commit.
- Do not open pull requests against this folder. The next copy overwrites them.
